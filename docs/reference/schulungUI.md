# Shiny UI Module for Gold-Standard Coder Training

Constructs the user interface container for the Coding Training
workflow.

## Usage

``` r
schulungUI(id)
```

## Arguments

- id:

  Character scalar module namespace identifier.

## Value

A Shiny UI tag list.

## Examples

``` r
if (FALSE) { # \dontrun{
schulungUI("mod_training")
} # }
```
