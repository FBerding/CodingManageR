# Shiny UI Module for Live Field Coding

Constructs the user interface container for the Live Coding workflow.

## Usage

``` r
kodierungenUI(id)
```

## Arguments

- id:

  Character scalar module namespace identifier.

## Value

A Shiny UI tag list.

## Examples

``` r
if (FALSE) { # \dontrun{
kodierungenUI("mod_codings")
} # }
```
